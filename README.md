**Small-scale homemade anti-drone turret**

A project inspired by Remote Weapon Station (RWS) and Counter-UAS (C-UAS) technologies, focusing on the application of computer vision and AI training using real-world data and various sensor inputs to identify potential threats, targets, and enemies. 

This project is entirely personal and academic in nature, with no profit motive whatsoever; it is solely intended as a subject of study and for advancement in related fields. 

**Skills developed:**
-Applied robotics 
-Computer vision 
-Electronics 
-Sensor-based identification 
-Coding  
-Regulations in military-industrial complexes 
-Handling of sensitive data 


Settled totally in Fortaleza, CE, Brazil
